# -phantoms-capstone-checkpoint
المرحلة الأولى - البيانات:
تم اختيار البيانات واستخراجها، ثم حفظها وإدارتها داخل قاعدة بيانات SQLite لضمان تنظيم البيانات وسهولة استدعائها.
​المرحلة الثانية - التنظيف والتجهيز:
تم معالجة القيم المفقودة، وتحويل البيانات الوصفية إلى رقمية، وتحديد المتغيرات المستقلة (Features) والمتغير الهدف (Label) بنجاح.
​المرحلة الثالثة والرابعة - التدريب والتقييم:
تم تقسيم البيانات وتدريب نموذجين هما Logistic Regression و Decision Tree. تم التقييم بناءً على Precision و Recall و F1-Score والـ Confusion Matrix لمعرفة النموذج الأدق عملياً.
​المرحلة الخامسة - قرار الـ Deep Learning:
المشكلة تعتبر من المشاكل الجدولية البسيطة التي تؤدي فيها خوارزميات الـ Machine Learning التقليدية أداءً ممتازاً وسريعاً، ولا تتطلب تعقيد الـ Deep Learning أو الشبكات العصبية.
